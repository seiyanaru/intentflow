## セクション 2: 軸別の調査サマリ

### 軸1: EEG/BCI文脈での prototype-based TTA（優先度A）

EEG-BCI における TTA 研究は 2023-2025 年に急速に発展した。最も包括的な研究は T-TIME (Li et al., IEEE TBME 2024) であり、約 20 手法を BCIC-IV 2a/2b 等で比較している。T-TIME は T3A をベースラインとして評価し、**高次元 EEG 特徴空間でのプロトタイプ構築が困難**と報告している点は本研究にとって重要な反証材料である。Wimpff et al. (2024) は EA + Adaptive BN + entropy minimization の組合せで OTTA を実現し、BFT (2025) ではさらに前方伝播のみの BN-free TTA に進展させた。BTTA-DG は Dirichlet 射影 + GMM 推論という独自のベイズ的アプローチで gradient-free 適応を実現している。**しかし、BN 統計更新をプロトタイプ EMA 更新に「明示的に置換」した EEG 論文は確認されなかった。** T3A のEEG適用が T-TIME で困難とされた事実は、単純な T3A 転用ではなく、hierarchical prototype（浅層/深層分離）や gating による選択的更新のような工夫が必要であることを示唆しており、本研究の設計方針を間接的に支持する。

### 軸2: BN-free OTTA の一般領域（優先度A）

BN-free TTA は CV 領域で複数の確立された手法が存在する。T3A (NeurIPS 2021) はプロトタイプのみで BN 不要、LAME (CVPR 2022) はモデルパラメータ不変でロジット調整のみ、Conjugate PL (NeurIPS 2022) は BN アフィンのみ（統計量は凍結）。SAR (ICLR 2023 Oral) は running statistics を凍結しアフィンパラメータのみを SAM で安定更新する設計で「BN 統計更新の不安定性」を動的分布変化環境で実証した。NOTE (NeurIPS 2022) は IN/BN 混合で時間相関ストリームに対応。最新では LSTM-Affine (2025) が BN を再帰的アフィン変換に完全置換し前方伝播のみで適応する手法を提案、BN-SFDA (AISTATS 2025) が BN 凍結下での共学習を提案している。**BN 統計更新の不安定性は一般領域で広く認知されており、「BN-free にする動機」は十分に強い。** 特に小バッチ・非定常ストリーム環境（EEG の本質的特性）では、BN 凍結の正当性は複数論文で理論的・実験的に裏付けられている。

### 軸3: Hierarchical/Multi-level Gating in TTA（優先度A）

層別ゲーティング TTA は 2024-2025 年に急速に発展した分野である。GALA (AAAI 2025)、LAW (WACV 2024)、LEAST (2024)、PALM (AAAI 2025)、Hi-Vec (WACV 2026) の 5 手法が層レベルの動的ゲーティングを実現している。GALA/LEAST は勾配アラインメント基準、LAW/PALM は Fisher 情報基準、Hi-Vec は Layer Agreement 基準を使用。TTN (ICLR 2023) は BN 層ごとのドメインシフト感度に基づく補間重みを学習する。**しかし、これらは全て「全層に同一基準を適用し、結果として層ごとに異なる扱いが創発する」設計であり、「浅層には基準X、深層には基準Y」のように深度に応じて異なるゲート条件を明示的に設計した論文は見当たらなかった。** 本研究の Tri-Lock gate を浅層/深層で別々に適用する設計は、この意味で新規性がある。ただし、PAINT (2024) が「浅層3ブロックのみ更新」という静的な浅層/深層分離を行っている点は、動機の先行事例として認識すべき。

### 軸4: EEG Inter-Subject Mixup（優先度B）

EEG における Mixup 研究は汎化目的の正則化として広く使われているが、被験者間シフトの直接的模擬として設計された研究は限定的。mixEEG (CogSci 2025 Oral) が被験者間 Mixup を FL 設定で明示的に扱った最新論文であり、被験者間の平均データを共有する設計が特徴。LMDA-Net (NeuroImage 2023) は学習時 Mixup を含むが被験者間シフト対策としてではない。**Inter-subject Mixup を source-side prototype 設計と組み合わせた論文は確認されなかった。** 「Mixup で中間的な被験者分布を生成し、その上で prototype を初期化する」という本研究の設計は、mixEEG の FL 設定とは異なる文脈での新規な組合せ。

### 軸5: Domain Generalization for EEG MI（優先度B）

EEG MI の DG 研究は 2024-2025 年に本格化した。EEG-DG (IEEE JBHI 2025) が周辺・条件分布の同時整合で BCIC-IV 2a に 81.79% を達成し、一部の DA 手法を上回る性能を示した。潜在分布探索 (Neurocomputing 2024) や特徴認識型不変表現 (Sci. Reports 2025) など多角的アプローチが提案されている。**DG + prototype-based OTTA のハイブリッド路線は EEG 領域で確認されなかった。** BTTA-DG がDG的source学習 + Bayesian TTA の組合せとして最も近いが、prototype EMA ではなく GMM-Dirichlet ベースであり、設計哲学が大きく異なる。一般 CV 領域では T3A 自体が DG 文脈で提案されたものであり（NeurIPS 2021 の DG セッション）、DG + prototype TTA の組合せは概念的に自然だが、EEG での実装は未踏。

### 軸6: TCFormer・近縁 EEG Transformer の TTA 適用（優先度B）

TCFormer (Altaheri et al., Sci. Reports 2025) は MK-CNN + Grouped Query Attention Transformer + TCN の 3 段構成で BCIC-IV 2a に 84.79% を達成した最新手法。**TCFormer に TTA を適用した論文は確認されなかった。** EEG Transformer 系全般（EEG Conformer, BIOT, BENDR）への本格的 TTA 適用もほぼ空白。Wimpff et al. の一連の研究 (2024-2025) は EEGNet 等の軽量 CNN を対象としており、Transformer のAttention モジュールや LayerNorm への適応は未検討。LoRA 系アダプタ (Springer 2024) が EEG の task adaptation に使われた例はあるが、test-time ではなく fine-tuning 文脈。**TCFormer + OTTA は完全に新規な組合せ。**

## セクション 3: 最近接 3 件の差分マトリクス

提案手法に最も近い既存研究として以下の 3 件を特定した。

| 軸 | 提案手法 | **[P1] BFT (Wimpff+, 2025)** | **[P2] T-TIME (Li+, 2024)** | **[P3] BTTA-DG (Luo+, 2025)** |
|-----|---------|------|------|------|
| **Train-time** | TCFormer + inter-subject mixup + prototype保存 | 標準的supervised学習（EEGNet等） | 複数source modelのアンサンブル学習 | DG的source学習 + Dirichlet射影ヘッド |
| **Test-time** | BN完全凍結 + prototype EMA更新 | BN不使用、前方伝播のみ（拡張+ランク集約） | エントロピー最小化 + 分布正則化 | GMM-Dirichlet ベイズ推論（gradient-free） |
| **Gating** | Tri-Lock gate (pmax×SAL×Energy) を浅層/深層別に適用 | なし（全サンプルに同一処理） | なし（全サンプルに適応） | なし（全サンプルにベイズ推論） |
| **Prototype使用** | 浅層/深層の階層的prototype、EMA更新、logits+距離併用 | なし（prototype不使用） | Source prototypeで初期化、EMAで追従 | なし（GMM-Dirichlet分布パラメータ） |
| **Dataset** | BCIC-IV 2a/2b | BCIC-IV 2a/2b, BNCI Horizon | BCIC-IV 2a/2b + 他複数 | BCIC-IV 2a/2b + OpenBMI |
| **Backbone** | TCFormer | EEGNet, ShallowConvNet等 | EEGNet, ShallowConvNet等 | EEGNet等（backbone非依存を主張） |

### 各論文との差分詳細

**[P1] BFT との差分:**
- BFT はデータ拡張ベースの前方伝播のみ適応であり、prototype を使わない。本研究は prototype EMA 更新を中核に据える。
- BFT は gating なし（全サンプル同一処理）。本研究は Tri-Lock gate による選択的更新。
- BFT は軽量CNN対象。本研究は TCFormer (Transformer)。
- **共通点:** BN不使用、EEG MI、OTTA。

**[P2] T-TIME との差分:**
- T-TIME はエントロピー最小化+アンサンブルでBN統計を更新。本研究はBN凍結+prototype。
- T-TIME は T3A を評価し「高次元でprototype構築困難」と報告。本研究は hierarchical prototype (浅層/深層分離) でこの問題に対処。
- T-TIME は single model ではなくアンサンブル。本研究は single model。
- **共通点:** EEG MI TTA、BCIC-IV 2a/2b。

**[P3] BTTA-DG との差分:**
- BTTA-DG は Dirichlet 射影 + GMM 推論。本研究は prototype EMA 更新。
- BTTA-DG は gradient-free だが prototype ベースではない。本研究は prototype 中心。
- BTTA-DG は backbone 非依存を主張。本研究は TCFormer 特化の設計。
- **共通点:** DG的source学習 + test-time 適応のハイブリッド、BN統計不使用。

## セクション 4: 新規性ギャップ評価

### 4.1 既に提案済みの要素

1. **BN凍結によるTTA**: SAR (ICLR 2023), BN-SFDA (AISTATS 2025), BFT (2025) 等で確立済み。EEGでもBFTが先行。
2. **Prototype-based TTA**: T3A (NeurIPS 2021) で確立済み。ただしEEGでの成功例は限定的。
3. **層別ゲーティングTTA**: GALA, LAW, PALM, Hi-Vec等で同一基準の層別適用は提案済み。
4. **EEG MI向けOTTA**: Wimpff et al. (2024), T-TIME (2024), BTTA-DG (2025) で枠組み確立済み。
5. **EEG MI向けDomain Generalization**: EEG-DG (2024) 等で活発に研究中。
6. **EEGデータ拡張としてのMixup**: LMDA-Net, mixEEG等で使用実績あり。

### 4.2 組み合わせとして新規な要素

1. **BN凍結 + prototype EMA更新 の EEG適用**: T3AのEEG適用はT-TIMEで困難と報告されているが、hierarchical prototype（浅層/深層分離）による解決策は未提案。**組み合わせとして新規。**
2. **DG的source学習 + prototype-based OTTA のハイブリッド**: 一般CVではT3A自体がDG文脈だが、EEGでinter-subject mixupによるDG学習とprototype OTTAの明示的組合せは未報告。**組み合わせとして新規。**
3. **TCFormer + TTA**: TCFormerへのTTA適用自体が未踏。**組み合わせとして新規。**
4. **Logits + prototype距離 の併用予測**: T3Aはprototype距離のみで予測するが、logitsとの併用は一般的でない。NOTE等のBN/IN混合に着想は近いが、予測段階での併用は新規性あり。

### 4.3 完全未提案の要素

1. **Hierarchical (shallow/deep) prototype の明示的分離設計**: 浅層と深層で別々のprototypeを保持し、別々のgate条件で更新する設計は、EEG・一般領域を問わず確認されなかった。**完全未提案。**
2. **Tri-Lock gate (pmax × SAL × Energy) の浅層/深層別適用**: 既存の層別ゲーティング手法（GALA, LAW等）は全層同一基準を適用するのに対し、浅層と深層で異なるゲート条件を明示的に設計するアプローチは未報告。**完全未提案。**
3. **Inter-subject mixup → prototype初期化 のパイプライン**: Mixupで被験者間シフトを模擬し、その上でsource-side prototypeを構築するパイプラインは未報告。**完全未提案。**

### 4.4 率直な批判（弱点・反論されうる点）

**批判1: T3AのEEG適用困難性への対処が不十分な可能性**
T-TIME (Li et al., 2024) はT3Aについて「高次元特徴空間でのプロトタイプ構築が困難」と明示的に報告している。本研究はhierarchical prototype（浅層/深層分離）でこれを解決しようとするが、浅層特徴は低レベル（空間フィルタ等）であり、クラス弁別性が低い可能性がある。浅層prototypeがクラス分離を維持できるかの実験的検証が不可欠であり、ここが破綻すれば設計全体の根幹が揺らぐ。

**批判2: Tri-Lock gate の複雑さと過剰設計の懸念**
pmax × SAL × Energyの3要素積をさらに浅層/深層で分離するのは、ハイパーパラメータ空間が広大になる。BFT (Wimpff et al., 2025) が「前方伝播のみ」の極めてシンプルな設計で競争力のある性能を出していることを考えると、「複雑なgating機構は本当に必要か？」「単純なconfidenceフィルタリング（EATAのような）で十分ではないか？」という反論が予想される。Ablation studyでTri-Lockの各要素の寄与を明確に示す必要がある。

**批判3: BN-freeにする動機の強さについて**
本研究の出発点は「shallow層のBN running_varを触ると悪化する」という実験的観察であり、これ自体は強い動機である。しかし、反論として「shallow_mean + deep_both (momentum=0.01) で既にbestなら、BNを完全に捨てる必要があるのか？」「BN統計の選択的更新（現在のbest手法）をさらに改良する方向ではダメなのか？」という疑問が生じる。BN完全凍結がBN選択的更新を性能で上回ることを示せなければ、「構造的にクリーン」という主張だけでは弱い。

**批判4: Source-side prototypeの品質依存性**
最終epochでのprototype保存は、source学習の収束状態に強く依存する。EEGの被験者間変動が大きい場合、source prototypeがtarget被験者にとって全く的外れな位置にある可能性がある。BTTA-DG (2025) がDirichlet分布パラメータという柔軟な表現を選んだのは、点推定（prototype）の脆弱性を意識した設計とも読める。Prototype初期化の頑健性について、EA (Euclidean Alignment) との組合せやrobust statisticsの導入が検討に値する。

**批判5: TCFormerへのTTA適用の正当性**
TCFormerにはBN層がどの程度含まれるか（LayerNorm主体の可能性もある）によって、「BN凍結」の意味自体が変わる。TCFormerの正規化層構成を精査した上で、BN凍結の効果を議論する必要がある。LayerNorm主体であれば、BN問題自体が存在しない可能性もある。

**批判6: 評価データセットの限界**
BCIC-IV 2a/2b は被験者数が9人/9人と少なく、被験者間変動の統計的有意性を示しにくい。OpenBMI (54人) やPhysioNet等のより大規模なデータセットでの検証が求められる。

### 4.5 新規性の総合評価

| 要素 | ステータス | 新規性の強さ |
|------|----------|------------|
| BN-free OTTA (一般) | 確立済み | 低い |
| BN-free OTTA (EEG) | BFTが先行するが少数 | 中程度 |
| Prototype-based TTA (一般) | T3Aで確立済み | 低い |
| Prototype-based TTA (EEG) | T-TIMEで困難と報告 | 中程度（課題解決として） |
| Hierarchical prototype (shallow/deep) | **未報告** | **高い** |
| 深度別異なるgate条件 | **未報告** | **高い** |
| Tri-Lock gate | 独自設計 | 高い |
| Inter-subject mixup → prototype | **未報告** | **高い** |
| DG + prototype OTTA (EEG) | **未報告** | **高い** |
| TCFormer + OTTA | **未報告** | 高い |

**結論:** 個々の要素（BN凍結、prototype TTA、層別ゲーティング、Mixup）は既存だが、(1) hierarchical shallow/deep prototypeの明示的分離、(2) 深度別の異なるゲート条件、(3) inter-subject mixupとprototype初期化の連携、の3点は完全未提案であり、十分な新規性がある。最大のリスクは「T3Aの高次元問題がhierarchical設計で本当に解決するか」の実験的検証と、「Tri-Lock gateの複雑さが性能向上に見合うか」のablation結果にかかっている。
